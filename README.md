# Abdul Aziz Dal — Senior Full Stack & AI Developer Portfolio

A modern, high-performance personal portfolio and interactive resume website built for **Abdul Aziz Dal** using **Next.js 16**, **React 19**, and **Tailwind CSS v4**.

---

## 🌟 Key Features

1. **Interactive Hero & Live Production Overview**:
   - Availability badges, AWS Certified Developer credentials, and quick contact action buttons.
   - 1-click clipboard copy for Email and Phone numbers with real-time feedback.
   - Interactive system overview terminal summarizing current enterprise roles.

2. **Interactive AI Resume Parsing & Candidate Match Simulator**:
   - Live interactive simulation representing the proprietary algorithm engineered for **HireSide ATS**.
   - Select candidates and target job descriptions to simulate LLM entity extraction and 5-tier multi-vector relevance scoring.
   - Toggle between visual scorecards and strict OpenAPI-compliant structured JSON outputs.

3. **Enterprise System Design & Architecture Inspector**:
   - Clickable multi-layer architecture breakdown detailing Next.js frontend, PHP API gateways, Redis distributed caching, LLM ingestion workers, and MySQL/S3 storage.

4. **Career Milestones & Detailed Product Breakdown**:
   - Complete history with **Verge (WebHR & HireSide)**, **Salesflo (Engage)**, and **Hidaya (LMS)**.
   - Detailed technical contributions, scaling metrics, and architecture accomplishments.

5. **Production Systems & Filterable Projects**:
   - Filter projects by category (`AI & ATS`, `Enterprise HRMS`, `Cloud & Merchandising`).
   - Detailed metric chips (e.g., 98% parsing accuracy, 3.5x faster queries, serverless Lambda/Athena).

6. **Technical Capabilities Matrix**:
   - Categorized across Frontend, Backend, Databases & Caching, AWS Cloud, AI Integration, and DevOps.
   - Live interactive search filter.

7. **Dedicated Print-Ready Resume (`/resume`)**:
   - ATS-compliant, cleanly formatted online resume.
   - 1-click "Print / Save as PDF" button with custom `@media print` CSS overrides.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **UI & Styling:** React 19, Tailwind CSS v4, Lucide React
- **Cloud & Tooling:** Webpack, TypeScript, ESLint

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```
